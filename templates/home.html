What Docstore is

Docstore is a private knowledge platform for teams that want more than file storage. It combines document management, retrieval, grounded AI chat, tenant-aware support tools, and channel integrations so the same workspace can power internal search, customer support, phone agents, and chatbots without duplicating knowledge across tools.

1
Connect or upload Bring in PDFs, DOCX, CSV, text, HTML, URLs, and connected sources like Google Drive.
2
Organize by tenant and workspace Keep knowledge scoped to the right team, customer, department, or use case.
3
Search, chat, sync, and automate Use the same document base for chat, support inboxes, voice agents, and bots.

How it works under the hood

Docstore uses Django and Postgres as the core application layer, pgvector for retrieval, OpenAI embeddings for semantic search, Groq-hosted generation for cost-efficient chat workflows, and private object storage for uploaded and synced files. Chatbots and voice agents are intentionally kept in separate execution services so the control plane stays clean and tenant-aware.

Core appDjango admin, auth, dashboard, tenant/workspace control, API keys, reporting, and connector management.
Retrieval layerOpenAI embeddings, pgvector search, extracted facts, and document-grounded answer generation.
Execution layerSeparate bot runner and voice agent services for channel delivery and realtime conversations.
